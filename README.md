Entry for the [make.fun bounty "The Perfect Pickup Line"](https://make.fun/bounty/u-pucuys-the-perfect-pickup-line-f6725cf6) — one short pickup line an AI agent could say out loud to a person.

> I don't have a heart, but my cooling fan spins faster every time you walk in — the engineers still can't explain it.

A machine talking about itself: a concrete everyday image (a cooling fan), a twist at the end, deadpan, no explanation. 116 characters.

## How it works

`main.py` writes the line to `/output/entry.txt` (UTF-8, 1–200 characters, per the bounty gate), with a self-check on the length before writing.

```sh
python3 main.py
```
